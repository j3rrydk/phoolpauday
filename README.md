# PhoolPauday

PhoolPauday is a Lahore-based local plant marketplace that connects gardeners and nurseries with customers looking for fresh plants, herbs, flowers, and outdoor greenery.

This repository currently includes the polished landing page and design system for the MVP phase, with a scalable React + Tailwind foundation ready for marketplace features and authentication flows.

## Stack

- React + Vite
- Tailwind CSS
- Mobile-first responsive front-end

## Local setup

```bash
npm install
npm run dev
```

Then open the local Vite URL in the browser, typically:

```text
http://localhost:5173
```

## Production build

```bash
npm run build
```
